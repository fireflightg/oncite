# oncite

The source for [oncite.vercel.app](https://oncite.vercel.app/).

## Update a release

Edit [`dist/content.json`](dist/content.json) to change the song title, image, captions, notes, SoundCloud player, social links, and listening-platform links.

Change `release.id` for every new drop. The site uses that ID to show the release popup once per visitor for each release.
